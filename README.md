# CodeForge Web IDE & Execution Sandbox

In-browser multi-language code editor with instantaneous code compilation, stdout execution, and snippet sharing.

---

## 🚀 Tech Stack
`React` `TypeScript` `Node.js` `Monaco Editor` `Docker` `Tailwind CSS`

---

## ✨ Key Features
- **Multi-language**: code execution supporting Python, JavaScript, C++, and Go
- **Monaco**: code editor with syntax highlighting, auto-completion, and error diagnostics
- **Configurable**: execution sandbox with timeout safeguards
- **Code**: snippet export, sharing links, and dark/light themes
- **Custom**: standard input (stdin) simulation for algorithmic problem testing

---

## 🛠️ Getting Started

### Prerequisites
- Node.js (v18+) or Python (3.10+) depending on project requirements
- Git

### Installation
```bash
# Clone the repository
git clone https://github.com/aqsam-husnain/codeforge-web-ide.git

# Navigate into project directory
cd codeforge-web-ide

# Install dependencies
npm install  # or: pip install -r requirements.txt

# Run the development server
npm run dev  # or: python app.py
```
